# iOS Target Context

## iOS-Specific Notes
- Use `NavigationStack` for navigation (DO NOT use deprecated NavigationView)
- Support Dynamic Type, Dark Mode, and VoiceOver
- Widget Extension for iOS widgets (WidgetKit)
- App Intents for Shortcuts and Siri

## Design Guidelines
- Follow Apple Human Interface Guidelines for iOS
- Bottom tab bar for main navigation
- Sheet presentation for create/edit flows
- Swipe actions for list items (delete, archive)
